# Privacy Policy — Whoop MCP Server (Personal Use)

This application is a personal, non-commercial integration that connects
a single user's Whoop account to their own Claude AI assistant via the
Model Context Protocol (MCP).

## Data Collected
This app accesses Whoop health and fitness data via the official Whoop
Developer API, including recovery scores, HRV, resting heart rate, sleep
data, and workout/strain data.

## Data Use
This data is used solely to provide the app owner with personalized
insights through their own Claude AI assistant. It is not used for any
other purpose.

## Data Storage
Data is cached locally in a SQLite database on the app owner's own
server infrastructure, used only to reduce redundant API calls to Whoop.

## Data Sharing
This data is not sold, shared, or disclosed to any third party. It is
accessed only by the app owner.
